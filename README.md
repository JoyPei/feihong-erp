# 飛泓科技 - 客戶授權與保固 ERP 系統 (Ragic 試算表風格 ＋ 內建 AI Agent)

本系統參考 **Ragic 客製化 ERP** 的經典架構設計，將「試算表的直覺操作」與「資料庫的嚴謹結構」完美結合，並整合了**內建 AI Agent**，實現 24 小時幫你查資料、抓異常、產報表的現代企業級體驗。

---

## 🌟 Ragic ERP 風格核心特色

1. **Ragic 經典雙視圖（一體兩面設計）**：
   - 📑 **列表頁 (Listing Page / Spreadsheet View)**：
     - 試算表高密度網格檢視，清楚掌握所有客戶合約。
     - 左側快速篩選樹（即時按保固狀態、業務人員、SI 廠商過濾）。
     - Ragic 經典工具列：`[＋ 新增]`、`[工具 ▼ (匯入/匯出 Excel)]`。
     - 點擊任何一筆資料，直接進入「表單頁」。
   - 📄 **表單頁 (Form Page / Detailed Sheet View)**：
     - 精緻企業單據設計，雙欄/四欄灰底標籤與填寫單元格。
     - 支援「上一筆 ‹ / 下一筆 ›」連續審閱切換、即時儲存、刪除與列印。
     - 涵蓋完整的 20 項標準業務欄位。

2. **🤖 內建 AI Agent 智慧助理 (Ragic 招牌核心亮點)**：
   - 位於右下角懸浮抽屜，隨開隨用。
   - **智能異常檢測**：一鍵抓出未填 S/O No. 或未定到期日的資料。
   - **保固與續約追蹤**：即時識別 30 天內即將到期之客戶名單與到期日。
   - **主管彙整週報生成**：自動統整全域數據、業務表現並提供行動建議。
   - **自然語言互動**：支援隨意提問（如「查一下松下產業」），並提供「在主列表中僅顯示這些資料」的聯動按鈕。

3. **📊 統計報表分析 (Analytics Tab)**：
   - 即時 KPI 看板（總數、保固中、即將到期、已過期）。
   - 各業務負責案件佔比長條圖與診斷建議。

4. **📥 Excel 雙向整合**：
   - 支援拖曳上傳 `.xlsx` 批次匯入，表頭智慧對應。
   - 一鍵匯出試算表為美觀 Excel。
   - 下載標準空白填寫範本。

## 📋 支援的資料欄位 (共 20 欄位)

| 分類 | 欄位名稱 | 說明 |
| :--- | :--- | :--- |
| **客戶與採購資訊** | 編號 (`item_no`) | 如 `1-1`, `2-1`, `4-1` |
| | 公司名稱 (`customer_name`) | 客戶/公司名稱 (必填) |
| | 代理商 (`agent`) | 代理商名稱 |
| | SI (`si`) | 系統整合商 (如 宏碁, 飛泓, 無) |
| | 業務 (`sales_rep`) | 負責業務 (如 Jenlin, Dennis) |
| | 採購日期 (`purchase_date`) | 採購建立日期 |
| | 採購內容 (`purchase_content`) | 採購品項與型號 (如 400MAC+P360*2) |
| | 收款階段 (`payment_stage`) | 如 全額, 1-4期 |
| | S/O No. (`so_no`) | 訂單編號 (如 SO-20260316-01) |
| **授權明細** | 授權證號 (`license_no`) | 軟體/系統授權編號 |
| | 授權數量 (`license_qty`) | 授權數量 (如 70U, 400MAC) |
| | 授權期間 (`license_period`) | 授權期限 (如 1年, 永久) |
| | 授權到期 (`license_expiry`) | 授權到期日 (如 2027/03/31, 永久) |
| **保固與售後** | 保固證號 (`warranty_no`) | 保固編號 |
| | 保固期間 (`warranty_period`) | 保固長度 (如 1年, 3年) |
| | 保固到期日 (`warranty_expiry`)| 保固截止日期 |
| | 保固狀態 (`warranty_status`) | 保固中 / 即將到期 / 已過期 / 永久授權 |
| | 保固工程師 (`warranty_engineer`)| 負責工程師 |
| | 出貨規章 (`shipping_regulation`)| 出貨條款規章 |
| | 備註 (`remark`) | 備忘說明或重要歷程 |

## 🚀 快速啟動方式

### 方法 1：Windows 雙擊啟動
直接雙擊專案目錄下的 `run.bat`。

### 方法 2：命令列啟動
```bash
# 1. 安裝套件 (初次使用)
pip install -r requirements.txt

# 2. 啟動 Web 服務
python app.py
```
啟動後打開瀏覽器訪問：**http://localhost:5000**
